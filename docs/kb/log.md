* **The full secret loop works end to end:** a bot files a request through its own CLI → it shows pending on the API → the operator saves the value → the response carries only a fingerprint and `granted_to: ["steve"]` → the request auto-resolves → the value arrives via the secret source at the bot's next session start. ## 2026-09-26 (later still)
* **`agent-computer` skill shipped + helper CLI built and verified.** `workspace/scripts/agent_computer.py` resolves which agent it is (from the fleet manifest, `$GROKBOT_AGENT`, or `$HERMES_HOME`) and routes every call to that agent's own display/socket. **14 of 15 verbs verified working one-shot**: whoami, screen, windows, tree, apps, elements, launch, type, key, hotkey, verify, rec, health, workspace, raw `call`. Real bugs found and fixed during the build: wrong manifest key (`agents`/`profile`, not `bots`/`name`); `launch_app` takes `name`+`additional_arguments` (not `command`); `verify_state` requires `pid`+`window_id` with predicates nested under `window`/`element`; X11 keyboard needs `delivery_mode="foreground"` (auto-escalated from `background_unavailable`); and pixel clicks need the window's `capture_id`.
* **The finding that shapes the integration:** a one-shot `docker exec cua-driver call` gets a **fresh authenticated transport lease each time**, so the accessibility snapshot and capture context expire before the call returns (`stale_element_token` / `capture_not_found`). **Pointer clicks therefore require a persistent MCP session** — `docker exec -i grokbot-computer cua-driver mcp --socket /run/cua-driver/<agent>.sock` registered as a stdio MCP server in the bot's profile, which also brings the per-session agent cursor. Everything else works one-shot. Architecture → [reference/agent-computer-architecture](reference/agent-computer-architecture.md).
* **Trap worth remembering:** typing into a **dead window** "succeeds" (`effect: unverifiable`) and changes nothing — Jim's screen didn't change until we launched a live `xterm`. Verify by screen diff, not by the tool's success message.
